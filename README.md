# studyflow

Hakim Learning Tracker.

## Overview

StudyFlow merupakan aplikasi mobile personal learning tracker yang dirancang untuk membantu pengguna mengatur, menjalankan, dan mengevaluasi aktivitas pembelajaran secara terstruktur.
Aplikasi ini memungkinkan pengguna mengelola kategori pembelajaran, membuat daftar tugas, menyusun jadwal mingguan, mencatat aktivitas belajar, dan memantau perkembangan belajar.
StudyFlow berfokus pada pengalaman penggunaan yang sederhana, produktif, dan mudah dipahami.
